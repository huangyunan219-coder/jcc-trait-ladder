# 羁绊天梯模拟器

金铲铲之战 **S18「自然之力」** 玩家工具。输入已有的转职种类与数量，寻找能激活更多非唯一羁绊的阵容，给出具体弈子和转职携带者。

**[在线使用羁绊天梯模拟器](https://huangyunan219-coder.github.io/jcc-trait-ladder/)** · 电脑、手机浏览器直接打开，无需安装或登录。

## 能做什么

| 上场人口 | 推荐范围 |
| --- | --- |
| 8 | 分别计算「不含五费」和「至少含一张五费」 |
| 9 | 所有费用均可使用 |
| 10 | 所有费用均可使用 |

- 所有方案永久排除卡兹克。
- 支持多个同类转职、必须上场/排除的弈子、已占装备格与拉克丝形态。
- 拉克丝九种形态互斥，对应元素贡献 2；远古巨龙占 2 人口、提供 2 份峡谷野怪。
- 转职必须分配给合法携带者；不能与原生羁绊重复、不能重复装备同类转职，每位弈子的总装备位最多为 3。
- 显示至多 10 套不同阵容，支持复制阵容、分享条件链接和本地保存条件。电脑与手机浏览器均可使用。
- 完整展示 2—16 羁绊奖励表，并高亮当前推荐阵容对应的档位。
- 浏览器后台计算，无账号、无运行时服务器、无分析追踪；页面使用本地游戏图标，字体有系统回退。

**羁绊数量不等于实战强度。** 同分方案按一星购买总价排序，未模拟装备效果、星级、战斗、经济、卡池概率或额外强化效果。

## 数据与准确性

当前采用 **18.2a 资料快照，核对日期 2026-09-24**。排除卡兹克后，包含 64 名基础弈子、72 个可上场变体、25 种当前计分羁绊、20 种转职。

中文英雄和门槛来自第三方图鉴；特殊机制使用 Riot 赛季资料交叉核对。数据不是腾讯官方实时接口，也不能保证覆盖此日期之后的热更新。

目前按绝命花妖和雷恩加尔的宿敌首档计入；组合羁绊「日月双蚀」是否计入国服羁绊天梯仍待确认，暂不计分。界面会展示这一口径。完整来源、羁绊门槛及待核实项见 [DATA_SOURCES.md](DATA_SOURCES.md)。

奖励表按用户提供的图片录入，覆盖 **2—16 羁绊**。详见 [REWARDS.md](REWARDS.md)。

## 本地运行

本项目不需要安装 npm 依赖或执行构建。`dist/` 同时是源代码与可部署的静态站点，**应提交到 Git**。

使用 Python 3：

```sh
git clone https://github.com/huangyunan219-coder/jcc-trait-ladder.git
cd jcc-trait-ladder
python -m http.server 5173 --bind 127.0.0.1 --directory dist
```

访问 `http://127.0.0.1:5173/`。也可使用任意静态 HTTP 服务器托管 `dist/`；直接双击 HTML 的 `file://` 方式不能可靠加载模块和 Worker。

若已安装 Node.js，`npm run dev` 会执行同一条 Python 启动命令。


## 搜索如何工作

1. 筛选合法棋子与形态，根据锁定棋子生成起始状态。
2. 对完整棋子池先进行多次随机起点的贪心填充和换子搜索，尽快找到可用方案。
3. 继续进行带乐观羁绊上界的分支搜索。每套阵容通过装备格最大流判断转职组合能否真正分配，再由规则函数复核。

默认每个模式搜索 5 秒；「再搜索 10 秒」会用新随机种子重新探索，并保留此前最佳方案。8 人口同时运行两种模式。实际耗时受设备和输入影响，时间预算不构成硬实时保证。

- **当前找到**：搜索预算用尽或用户停止，未证明不存在更好的组合。
- **已证明最多**：当前数据与约束下完成穷举及安全剪枝，能够确定最大羁绊数；不代表列出了所有同分方案。
- **没有合法阵容**：只有完整搜索完成且无解时才显示；超时未找到结果会单独说明。

修改条件会中止旧 Worker 并清空旧结果，避免用上一组转职展示阵容。结果必须恰好填满选择的人口。

## 部署和搜索收录

网站通过 GitHub Pages 公开托管 `dist/`，使用 HTTPS，不需要数据库。`.github/workflows/check.yml` 会在测试与语法检查通过后自动发布 `main`；Pull Request 只运行检查，也可通过 Actions 的 `workflow_dispatch` 手动重新发布。

正式地址为 <https://huangyunan219-coder.github.io/jcc-trait-ladder/>。首页已设置 canonical 与分享地址，并提供 `sitemap.xml` 和 `robots.txt`。更换域名时需同步修改这三处地址及本文件中的在线入口。本地托管身份配置不进入开源仓库。

GitHub 仓库让别人获取源代码；公开网站地址让别人直接使用。首页已有静态中文标题、简介和规则说明，搜索条件放在 URL 片段中，避免为每种配置生成重复索引页。

- [Bing Webmaster Tools](https://www.bing.com/webmasters/about)
- [百度搜索资源平台](https://ziyuan.baidu.com/)

提交不保证被收录、排名或收录时间；这些步骤需要对应站长账号。详见 [Google 搜索工作原理](https://developers.google.com/search/docs/fundamentals/how-search-works)。
